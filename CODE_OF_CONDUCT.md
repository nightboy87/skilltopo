# Code of Conduct

## Our standard

SkillTopo is a small open source project for skill routing metadata, evaluation, and integration examples. Discussions should stay technical, specific, and respectful.

Expected behavior:

- Use clear, constructive language.
- Focus criticism on code, documentation, tests, and project scope.
- Keep examples synthetic unless you have explicit rights to publish the content.
- Respect maintainers' decisions about project scope, safety boundaries, and licensing.

Unacceptable behavior:

- Harassment, insults, threats, or targeted personal attacks.
- Publishing private paths, credentials, tokens, logs, private skill libraries, or proprietary prompts.
- Submitting copied third-party skill content without permission.
- Pressuring maintainers to add features outside the project's stated scope.

## Scope

This code of conduct applies to project repositories, issues, pull requests, discussions, and other public project spaces.

## Enforcement

Maintainers may edit, hide, close, or delete comments, issues, pull requests, or discussions that violate this code of conduct. Repeated or severe violations may lead to a temporary or permanent ban from project spaces.

## Reporting

Report conduct issues through the repository's security or maintainer contact channel. Include links, screenshots, and a concise description when possible.
